# Five-day close example

Synthetic multi-ERP close for period **2026-06** (NetSuite US, SAP DE, Xero UK).

```bash
npm run example:close
```

See the cookbook in the package [README](../../README.md#cookbook-five-day-close--ap-exceptions) for what is illustrative versus the deterministic engine, and [docs/five-day-close.md](../../docs/five-day-close.md) / [docs/ap-exceptions.md](../../docs/ap-exceptions.md) for the gate list and taxonomy.
